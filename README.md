# Sodiq Olamide — Portfolio

Personal portfolio website for Sodiq Olamide, a full-stack web developer based in Nigeria.

## Built With

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## Featured Work

- **VerifiedNG** — verification and local-services platform
- **Oyincakesandmore** — business website for a bakery/catering brand
- **My Portfolio** — personal developer portfolio

## Structure

This is a lightweight static site. The portfolio is intentionally kept simple: the main website lives in `index.html`, while the profile image and custom-domain configuration are kept as separate repository files.
